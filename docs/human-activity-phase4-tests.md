# Phase 4 テストリスト

添付実装依頼を優先し、月表示と人間の独立集計を小さなRed→Green→整理で実装する。合成データだけを使う。

- [ ] 日別の種別内和集合・全対象和集合、別種別の重複、点の存在、空白の保持
- [ ] フィルタ前の種別時間と、選択種別だけの合計を分離する
- [ ] 日跨ぎ・月跨ぎ・DST23/25時間・欠けた暦日・範囲外開始の長い区間
- [ ] 50,000件を超える月も日別集計は切捨てず取得し、応答を最大62日へ制限する
- [ ] 現在の物理ソースだけを集計し、OFF時は集計IPCを拒否する
- [ ] 設定/日付/ビュー/タイムゾーン/種別/同期の変更と遅延応答の競合を防ぐ
- [ ] AIヒートマップ背景・集計値を維持し、人間3種別の独立バーと凡例を追加する
- [ ] バーを実際の日長でスケールし、種別間重複を24時間の内訳と誤表示しない
- [ ] 人間だけの記録・0秒点の日が選択でき、日別詳細はAIと人間を分ける
- [ ] 人間の日別一覧にも種別フィルタとまとめ表示/記録単位を適用する
- [ ] 日/週/月の人間独立集計にフィルタを反映し、内訳合計が総時間を超える理由を説明する
- [ ] サイドバーはフィルタ前の時間を保持し、取得失敗を正常な0時間と誤表示しない
- [ ] 機能OFF時は人間のバー/集計/一覧を除去し、古い応答で復活しない
- [ ] 許可情報だけのIPC/画面/診断、秘密文字列・ID・ソース情報の非露出
- [ ] 最小ウィンドウ/キーボード/ライト・ダーク/Windows native E2E
- [ ] 全回帰・型/lint/fmt/Clippy・ビルド・自己レビュー
- [ ] PR/CI/通常マージ/マージ後CI/main更新/専用worktreeとbranch削除

最終的な反復性能、writer/WAL/RSS/UI応答と全経路の漏洩試験はPhase 5で完遂する。
