# 人間の2列表示と同期予定時刻のテスト

- [ ] 日・週・月のバーとフィルタ・集計を娯楽/非娯楽（不明含む）の2分類で揃え、原分類は保持
- [ ] 非娯楽と不明の重複を二重加算せず、空白・点・日付境界・種別間の重なりを保持
- [ ] 次回予定は実際の前回試行完了から1時間、自動OFF/同期中/初回待機では状態を説明
- [ ] 最終成功時刻を変更なし確認でも更新し、原本欠落や再起動時には保存済み時刻を復元
- [ ] 失敗で最終成功を更新せず、Root切替/OFF/取消しで別ソースの時刻を混在させない
- [ ] 時刻を設定タイムゾーンで表示し、状態通知と自動更新ON/OFFで表示を更新
- [ ] 低い画面と長いラベルでも見出し・同期・設定を操作できる
- [ ] 全回帰/静的検査/ビルド/Windows native/合成画面確認

運用終了条件: PR CI/通常merge/postCI/main同期/専用worktreeとローカル・リモートブランチの通常削除。
