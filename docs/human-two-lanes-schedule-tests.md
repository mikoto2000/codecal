- [x] 日・週・月のバーとフィルタ・集計を娯楽/非娯楽（不明含む）の2分類で揃え、原分類は保持
- [x] 非娯楽と不明の重複を二重加算せず、空白・点・日付境界・種別間の重なりを保持
- [x] 次回予定は実際の前回試行完了から1時間、自動OFF/同期中/初回待機では状態を説明
- [x] 最終成功時刻を変更なし確認でも更新し、原本欠落や再起動時には保存済み時刻を復元
