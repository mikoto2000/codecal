# 人間の自動同期とサイドバーのテスト

- [ ] 人間の自動確認・変更通知による同期は前回完了から1時間空け、通知を集約する
- [ ] 初回ON・Root変更・手動同期は待機せず、自動更新OFF・機能OFFでは自動取得しない
- [ ] 1時間境界・変更なしスキップ・失敗後の再試行・保存先切替を短い試験用間隔で実ワーカー検証する
- [ ] 同期中に届いた通知を次回へ保持し、自動更新OFFへの変更で古い予約を解除する
- [ ] 同期状況・エラー・診断・手動再同期を左メニューの人間セクション末尾へ移す
- [ ] 狭い高さ、長いエラー、ライト/ダークでも同期ボタンと設定が操作できる
- [ ] AIの自動更新間隔とReiのデータ・設定は変更しない
- [ ] 全回帰・静的検査・ビルド・Windowsネイティブ・画面確認

運用終了条件: PR CI、通常マージ、マージ後CI、main更新、専用worktreeとローカル/リモートブランチの通常削除。
